- RAG over uploaded documents, and cross-channel duplicate detection with OpenAI embeddings + pgvector.
- An anomaly pipeline that detects in SQL first and only calls the LLM to explain what it flags.
- Next.js, PostgreSQL (Neon), Drizzle ORM. *(private repo)*

**[Tarif](https://tarif.ae)**: prices a UAE car trip before you drive it, with Salik and Darb tolls plus fuel for each route option, and a monthly driving budget on top. Express + PostgreSQL API with a cost engine on the Google Routes API, React Native app in development. *(private repo)*

**[Maestro](https://github.com/KarimUOB/Maestro)**: desktop app for running several AI coding agents in parallel, each in its own git worktree. Tauri 2 (Rust) + React, works with GitHub and GitLab. Open source, MIT.
